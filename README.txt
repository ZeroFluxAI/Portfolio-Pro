MUSHAHID ALI KAZMI — PORTFOLIO REFRESH

Files
- index.html: main portfolio page; all original sections and course/specialization entries retained.
- style.css: responsive visual system, animated gradient hero, subtle grid/ambient lighting, glass cards, reveal transitions, light/dark theme, mobile menu styling.
- script.js: theme toggle, credential preview modal, mobile navigation, scroll progress, section reveal, active navigation, cursor glow, and interactive CLI commands.

Preview locally
1. Keep all three files in the same folder.
2. Open index.html in a modern browser. Internet is needed for the existing Tailwind CDN, Google Fonts, and Font Awesome imports.

Publish to GitHub Pages
1. Back up the existing repository first.
2. Upload/replace index.html, style.css, and script.js in the repository root.
3. Commit the changes and allow GitHub Pages to redeploy.

Important notes
- The credential preview modal is a visual preview, not proof of verification. Add actual credential URLs/IDs to the relevant cards when available.
- The original contact information and public profile details were preserved except stray citation artifacts and any father-name-labelled field (none was present in the supplied HTML).
- This package does not publish changes to the live website automatically.
